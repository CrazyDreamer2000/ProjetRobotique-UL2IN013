# Documentation sur le Projet Robotique : « Robot Dexter »

## 1. Introduction

Le projet **« Robot Dexter »** vise à développer une plateforme de simulation de mouvement permettant de contrôler et d’expérimenter les déplacements du robot Dexter dans un environnement virtuel.

Cette démarche favorise :

* L’apprentissage de la programmation robotique.
* La validation d’algorithmes de mouvement.
* La préparation à des tâches robotiques réelles sans risque matériel.

## 3. Les Objectifs

L’objectif principal est de concevoir un environnement de simulation robuste pour le robot Dexter, afin de lui permettre d’exécuter différentes tâches, allant des plus simples aux plus complexes.

### Détail des missions

| Type de tâche | Mission | Description |
| --- | --- | --- |
| **Tâches simples** | **Tracer un carré** | Programmer le robot pour qu’il dessine une figure géométrique précise. |
|  | **Approche d'un mur** | S'approcher le plus près possible d'un obstacle sans le toucher (gestion des capteurs). |
|  | **Suivi de balise** | Développer un algorithme de détection et de suivi d'une cible mobile. |
| **Tâches complexes** | **Chat et Souris** | Simuler une interaction dynamique (poursuite ou évitement). |
|  | **Patrouille** | Surveiller une zone définie et détecter toute intrusion. |

## 4. Ressources et Outils Utilisés

Le projet s'appuie sur une pile technologique moderne pour la gestion et le développement :

* **GitHub** : Hébergement du code source et gestion du versioning (Git).
* **Python** : Langage de programmation principal pour les algorithmes.
* **VSCode** : Environnement de développement (IDE) utilisé pour le codage.
* **Trello** : Gestion de projet agile pour l'organisation et le suivi des tâches.
* **Turtle** : Bibliothèque Python utilisée pour la visualisation graphique des mouvements du robot.
